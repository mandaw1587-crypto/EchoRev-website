# Brand Block — collect this before building

Ask the user for each field. If they don't have an answer, use `[PLACEHOLDER]` in the copy and flag it back to them at the end — never invent a stat, quote, or number.

- **Brand name**
- **Accent color + background color** (hex codes if they have brand colors; otherwise suggest based on vibe)
- **Hero headline** (one short line)
- **Hero subhead** (one sentence)
- **Primary CTA text** (e.g. "Wishlist on Steam", "Book a Call", "Get Started")
- **3 feature/benefit lines** (short, punchy — one per card)
- **Stats row** (3-4 real numbers/facts — never invented)
- **How it works** — 3 short steps
- **Gallery caption line** (one line, optional)
- **Closing CTA band** — headline, subhead, button text
- **Source video** — path or description of the clip(s) to use, in order if chained

## Example — filled (for shape/tone reference only, not a template to copy verbatim)

**GAME — "AETHERIA"**

Pain point it solves: indie game studios can't make a static store page feel like their world, so players don't wishlist. An immersive scroll that flies you through the world before you buy is the pitch. This is a wishlist/beta-signup page.

- Brand: AETHERIA, an open-world fantasy RPG.
- Accent: teal on near-black.
- Hero headline: "Fall into Aetheria."
- Hero subhead: "An open world that rebuilds itself around every choice you make. Scroll to step inside."
- Primary CTA: "Wishlist on Steam"
- Features (3 cards): "One living world, zero loading screens." / "A sky that remembers you. Regions shift with your story." / "Play your way. Fight, build, or just wander."
- Stats row: "12 regions" / "60+ hour campaign" / "0 loading screens" / "1 world, always yours"
- How it works (3 steps): "1. Wishlist and lock founder pricing. 2. Get your early beta key this winter. 3. Play the full realm on launch day."
- Gallery caption: "Concept worlds from the Aetheria art team."
- Closing CTA band: headline "The realm opens soon." / subhead "Wishlist now, be first through the gate." / button "Wishlist on Steam"
